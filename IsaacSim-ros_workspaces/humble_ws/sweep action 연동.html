Sweep Action 연동 및 실행 절차

1. Action 정보

Action name: /sweep
Action type: turtlebot3_msgs/action/Sweep

Goal은 별도 데이터가 없으며, /sweep Action 호출 자체가 장애물 제거 동작 실행 요청을 의미한다.

Feedback은:

string state

Result는:

string result_code

결과값은 다음과 같이 사용한다.

SUCCESS → 장애물 제거 성공, Navigation 계속
STALL   → 임시 안전 컷오프 발생, fixed 처리 후 우회
ERROR   → 기타 실행 오류

기존 obstacle_clear_sequence.py는 실행 단계 상태를 /sweep_stage로 발행하고, Sweep 구간에서 임시 안전 컷오프 발생 시 동작을 중단하도록 구성되어 있다. 붙여넣은 마크다운 붙여넣은 마크다운

2. Manipulation 측 실행

먼저 OpenMANIPULATOR-X 관련 컨트롤러가 정상 실행되어 있어야 한다.

그다음 터미널에서:

cd ~/turtlebot3_ws
source install/setup.bash

Action Server 실행:

python3 ~/turtlebot3_ws/scripts/festa_action/sweep_action_server.py

정상 실행 시 서버는 /sweep Action 요청을 대기한다.

3. Action Server 확인

새 터미널에서:

cd ~/turtlebot3_ws
source install/setup.bash
ros2 action list

목록에 다음이 보여야 한다.

/sweep

상세 확인:

ros2 action info /sweep

Action 타입 확인:

ros2 action type /sweep

정상이라면:

turtlebot3_msgs/action/Sweep

가 출력되어야 한다.

4. Action 인터페이스 확인

ros2 interface show turtlebot3_msgs/action/Sweep

핵심 내용은 다음과 같아야 한다.

---
string result_code
---
string state

5. Navigation 측 실행 전 준비

Navigation 측 터미널에서도 동일하게 워크스페이스를 source 해야 한다.

cd ~/turtlebot3_ws
source install/setup.bash

Navigation 코드에서는:

from turtlebot3_msgs.action import Sweepfrom rclpy.action import ActionClient

를 사용하고,

self.sweep_client = ActionClient(    self,    Sweep,    '/sweep')

형태로 Action Client를 생성한다.

6. Navigation 측 요청

Goal에는 별도 데이터가 없으므로:

goal_msg = Sweep.Goal()

을 생성한 뒤 전송한다.

self.sweep_client.send_goal_async(    goal_msg,    feedback_callback=self.feedback_callback)

7. 실행 중 Feedback

Manipulation 측에서 다음과 같은 state가 전달된다.

REAR_PLACE
P_REAR_PRE_SWEEP
P_PRE_SWEEP
APPROACH_CONTACT
SWEEP_AFTER_CONTACT
RETREAT
REAR_REPICK
SEQUENCE_COMPLETE

예외 상태는:

FAILED
SAFETY_STOP
SEQUENCE_FAILED

이다.

8. 최종 Result 처리

Navigation 측에서는 최종적으로:

result.result_code

를 확인하면 된다.

처리 기준:

if result.result_code == 'SUCCESS':    # 이후 Navigation 계속elif result.result_code == 'STALL':    # 해당 장애물을 fixed로 처리    # 우회 경로 생성elif result.result_code == 'ERROR':    # 예외 처리

9. 전체 실행 흐름

1. Manipulator controller 실행
2. source ~/turtlebot3_ws/install/setup.bash
3. sweep_action_server.py 실행
4. ros2 action list 로 /sweep 확인
5. Navigation에서 /sweep Goal 전송
6. Manipulation에서 obstacle_clear_sequence.py all 실행
7. 실행 중 state Feedback 전달
8. SUCCESS / STALL / ERROR 반환
9. Navigation에서 결과에 따라 계속 주행 또는 우회
